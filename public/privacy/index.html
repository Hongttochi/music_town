개인정보처리방침

MUSIC TOWN은 캐릭터로 공원을 산책하고 음악 활동에 참여하는 서비스입니다. 아래 내용은 현재 개발 버전이 다루는 정보와 공개 범위를 설명합니다.

1. 처리 목적과 항목

캐릭터 좌표는 게임 내 위치이며 기기의 GPS 위치를 수집하는 기능은 없습니다. Google 계정 비밀번호를 직접 받지 않으며, 계정 정보는 인증과 계정 관리에 사용합니다. 현재 앱에는 광고·방문 분석 스크립트, 결제, AI 입력 수집, 음성 송출·녹음 기능이 구현되어 있지 않습니다.

처리의 법적 근거는 필수적인 계약 이행에 필요한 처리와 별도 동의가 필요한 처리를 구분하여 정식 공개 전 확정합니다. 선택 프로필의 공개·제공 범위에 별도 동의가 필요한지도 함께 검토합니다. 이 방침 열람이나 소셜 로그인 자체를 모든 처리에 대한 일괄 동의로 간주하지 않습니다.

2. 다른 이용자에게 보이는 정보

같은 채널 이용자에게 캐릭터 이름·외형·뱃지, 역할, 자기소개, 등록한 SNS 주소, 게임 내 위치와 공연·대기 상태가 전달됩니다. 현재 구현은 사용자 ID도 채널 상태에 포함합니다. 로그인 이메일·소셜 계정 원본 프로필·인증 토큰은 이 채널 상태에 포함하지 않습니다. 자기소개와 SNS 주소에 타인의 정보나 공개를 원하지 않는 정보를 적지 마세요.

광고주에게 개인정보를 판매하거나 광고 목적으로 제공하는 기능은 없습니다. 법률상 근거가 있는 기관의 요청에 응하는 경우에는 적법한 범위인지 확인한 뒤 필요한 정보만 처리하도록 운영 절차를 마련합니다.

3. 보유 기간과 파기

  • 계정·프로필: 현재 자동 만료·회원 탈퇴 기능이 없어 운영자가 계정을 삭제하기 전까지 저장됩니다. 정식 운영 전에 탈퇴·삭제 접수 절차, 처리 기한, 법정 보관 예외와 백업 삭제 주기를 확정해야 합니다. 로그아웃은 탈퇴나 프로필 삭제가 아닙니다.
  • 채널 접속·공연·대기: 퇴장·종료·취소 등에 따라 활성 레코드를 정리합니다. 접속 갱신이 45초 이상 끊긴 세션은 다음 서버 정리 호출에서 삭제됩니다. 별도 예약 정리 작업은 없으므로 정확히 45초 뒤 삭제되는 것은 아닙니다.
  • 브라우저 정보: 사이트 데이터 삭제 또는 항목 삭제 전까지 남을 수 있습니다. 로그아웃 후에도 캐릭터·프로필 초안과 팔로우 설정은 남습니다. 이전 버전의 데모 신고 기록이 남아 있다면 사이트 데이터 삭제로 지울 수 있습니다.
  • 신고 정보: 운영자 검토용 DB에 저장되며 다른 이용자에게 공개되지 않습니다. 현재 자동 삭제 기간은 설정되지 않았으며, 정식 운영 전 보유·파기 기간을 확정해야 합니다. 계정 삭제 시 연결된 계정 ID는 제거되지만 신고 본문·대상 이름은 자동 삭제되지 않습니다.
  • 호스팅·인증 로그와 백업: 제공업체의 실제 수집 항목·보관 기간·삭제 방법은 아직 확인되지 않았습니다. 운영 설정을 확인하여 확정 방침에 기재해야 합니다.

현재 DB는 인증 계정 삭제 시 연결된 프로필·세션·공연·대기 데이터를 연쇄 삭제하도록 구성되어 있습니다. 활성 DB 삭제가 로그·백업까지 즉시 삭제한다는 뜻은 아닙니다. 확정 방침에서는 목적 달성 후 파기 절차와 복구 방지 조치를 실제 운영에 맞게 명시합니다.

4. 외부 서비스·처리 위탁·국외 이전

  • Supabase: 인증, 데이터베이스, 채널 상태 갱신에 사용합니다. 계약상 수탁 법인·연락처, 리전·이전 국가, 이전 시기·방법, 항목·목적·보유 기간과 이전 근거는 계약 및 콘솔 확인이 필요합니다.
  • Google·카카오: 이용자가 선택한 소셜 로그인을 처리합니다. 제공자가 독립적으로 처리하는 정보에는 해당 제공자의 정책이 적용되며, 로그인 제공자를 일률적으로 서비스의 수탁자로 분류하지 않습니다.
  • jsDelivr: 앱의 Pretendard 글꼴을 외부 CDN에서 불러옵니다. 요청 과정에서 IP 주소, 브라우저 정보 등 네트워크 요청 정보가 전달될 수 있습니다. 보관·이전 세부사항을 확인하거나 글꼴을 자체 호스팅해야 합니다. 이 문서 페이지는 외부 글꼴을 요청하지 않습니다.
  • 웹 호스팅: 업체·지역·접속 로그 설정 미정입니다. 실제 배포 후 확인해야 합니다.

국외 이전이 있는 경우 이전받는 자와 연락처, 국가, 시기·방법, 항목, 목적·보유 기간, 적용 근거 및 거부 방법·효과를 구체적으로 안내해야 합니다. 해외 서비스를 사용한다는 문장만으로 이 안내나 필요한 동의를 대신하지 않습니다.

5. 브라우저 저장소와 외부 링크

현재 앱은 로그인 유지와 설정 저장에 localStorage를 사용합니다. 브라우저의 사이트 데이터 관리에서 확인·삭제할 수 있고, 차단하면 로그인 유지나 설정 저장이 제한될 수 있습니다. 앱이 직접 설치하는 광고 쿠키는 없습니다. 소셜 로그인 제공자·호스팅의 쿠키와 로그는 별도 확인 대상입니다. Instagram·SoundCloud 링크를 누르면 외부 사이트로 이동하며 해당 사이트의 정책이 적용됩니다.

7. 안전조치·아동·자동화 처리

소스에는 HTTPS 기반 인증 연결, 프로필 소유자별 DB 접근 정책과 인증된 서버 함수가 구성되어 있습니다. 실제 운영 DB에 정책이 적용되었는지, 관리자 권한·접속기록·백업이 적절한지는 별도로 점검해야 합니다. 자동화된 개인정보 기반 의사결정이나 가명정보 분석 기능은 구현되어 있지 않습니다.

만 14세 미만 이용에 관한 운영 방침 및 법정대리인 동의 절차는 아직 마련되지 않았습니다. 정식 운영 전 이용 연령과 필요한 확인·동의 절차를 확정해야 하며, 약관 문구만으로 동의 절차를 대체하지 않습니다.
