# 하트 랭킹

## 현재 구현

- 상단 트로피 버튼에서 주간 / 누적 랭킹을 전환하고 뮤지션 프로필을 열 수 있다.
- 누적 하트는 현재 유효한 하트 전체이며 주가 바뀌어도 초기화하지 않는다.
- 주간 하트는 한국 시간 월요일 00:00 이상, 다음 월요일 00:00 미만에 처음 받은 유효한 하트다. 서버 시간으로 계산하므로 별도 초기화 작업이 필요 없다.
- 기존 계정당 대상별 하트 한 번, 취소 기능을 유지한다. 취소 시 두 집계에서 빠지며 다시 보내면 최초 수신 주로 복원된다. 이전 주 하트를 다시 보내 이번 주 점수를 올릴 수 없다.
- 팬 등록은 랭킹에 포함하지 않는다. 프로필 작성을 마친 뮤지션 중 해당 기간에 하트가 있는 사람만 표시한다.
- 동점은 공동 순위(1, 1, 3)이며 동일 순위 내 표시 순서는 계정 ID로 고정한다. 최대 100명, 화면이 보일 때 15초마다 갱신한다.
- 프로필에서 누적 하트와 주간 하트를 각각 확인할 수 있다. 기존 하트 수신 시각을 보존해 이관한다.

## 적용

기존 마이그레이션 적용 후 `supabase/migrations/202611100001_heart_rankings.sql`을 운영 DB에 적용하고 프런트엔드를 배포한다. 이 변경은 로컬 코드 및 마이그레이션 준비이며 운영 DB 적용을 의미하지 않는다.

## 추후 메인 콘서트 연동

주간 랭킹 마감 후 상위 3명에게 출연 기회를 제공한다. 직전 콘서트 실제 출연자는 다음 회차 선정에서만 제외하고 랭킹 표시는 유지한다. 불참하면 다음 대상에게 기회를 제공한다.

콘서트 시설 구현 시 마감 순위 스냅샷, 회차별 실제 출연 기록, 출연 의사 및 일정 확인을 함께 구현해야 한다. 마감 후 하트 취소나 프로필 변경으로 이미 확정된 선정 결과가 바뀌면 안 된다. 경계 동점으로 3명을 초과하는 경우의 선정 방식은 콘서트 기능 도입 전에 확정한다. 현재 랭킹은 출연 확정 명단이 아니다.
