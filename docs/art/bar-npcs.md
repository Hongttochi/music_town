# 달빛 바 NPC

2026-11-08 imagegen으로 제작한 투명 배경 2D 캐릭터. 원본 PNG와 웹용 높이 512px WebP를 함께 보관한다.

- 루나: 크림색과 캐러멜색의 늘어진 귀 강아지. 네이비 정장, 금색 장식, 갈색 구두. 다정하고 예의 바른 문지기. 정면 전신, 손으로 그린 부드러운 치비 스타일.
- 레오: 은회색 고양이. 녹색 눈, 차분한 표정, 차콜 조끼, 버건디 보타이, 크림 셔츠와 검정 앞치마. 정면 전신, 같은 2D 스타일.

장면에서는 카메라를 향하는 스프라이트로 표시한다. 대화창은 루나의 동일 이미지를 사용한다.
