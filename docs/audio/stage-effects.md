# 공연 음향 설정

공연 중 `음향 설정`에서 마이크 볼륨(0–150%), 리버브(0–60%), 에코(0–50%)를 조절한다. 원음·작은 공연장·재즈바 프리셋과 마지막 설정의 기기별 저장을 제공한다. 빈티지 음향 장비 형태의 노브를 드래그하거나 방향키로 돌려 조절하며, Shift 드래그는 미세 조절을 지원한다.

`useStageMicrophone`은 마이크 입력을 Web Audio의 dry/reverb/delay 경로에 연결하고, 볼륨 및 피크 압축을 거친 `MediaStreamDestination`을 반환한다. 기존 `useLiveAudio`가 이 출력 트랙을 복제해 LiveKit에 게시한다. 노브 변경은 노드 파라미터만 조절하므로 송출 트랙을 재생성하지 않는다. 로컬 스피커 모니터링은 연결하지 않는다.

오디오 컨텍스트가 일시 중지되면 출력 스트림을 게시하지 않고 `마이크 소리 시작` 버튼을 표시한다. 마이크 끄기, 권한 해제, 공연 종료, 페이지 이탈 시 원본 입력과 효과 출력 및 컨텍스트를 정리한다.

검증: Chromium OfflineAudioContext의 합성 신호로 원음/음소거/리버브 잔향/에코 반복을 확인했다. 브라우저에서 설정 변경 중 트랙 ID 유지, 프리셋/노브 드래그 및 방향키, 706×304·390×700 화면, 마이크 끄기 및 공연 종료 정리를 확인했다. 실제 두 기기 간 LiveKit 수신 음질과 iOS 실기기 지연은 별도 확인이 필요하다.
